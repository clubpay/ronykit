Localized strings via `golang.org/x/text` with per-request locale on context.

## Usage Hint

```go
bundle := i18n.InitLanguage(language.English, catalog)
msg := i18n.TextCtx(ctx, key, args...)
```

- `i18n.InitLanguage(lang language.Tag, catalog catalog.Catalog) Bundle` at startup (often `pkg/i18n`).
- `i18n.TextCtx(ctx, msg, args...)` for locale-aware user-facing text.
- Do not hand-roll catalogs or `map[string]string` translation tables in feature code.
